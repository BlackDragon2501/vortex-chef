# Vórtex Chef

Vórtex Chef, de Vortex Company: recetario local con ingredientes, pasos, etiquetas y favoritas; escala porciones y genera listas de compras agregadas (une ingredientes repetidos de varias recetas) y agrupadas por pasillo del supermercado, con casillas de comprado y copia al portapapeles. Recetas en IndexedDB, lista en localStorage. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- IndexedDB (recetas) + localStorage (lista de compras)
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
